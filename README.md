# Fardeen Raza — Portfolio

A responsive, static portfolio built with semantic HTML, CSS, and vanilla JavaScript. No package installation or build step is required.

## Run locally

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000>.

## Deploy to Vercel

Import this Git repository in Vercel and use the repository root as the project root. It is a static site, so no build command or output-directory override is needed. `vercel.json` configures security response headers and clean URLs.

## Included

- Light/dark theme, responsive navigation, project details, and email contact actions
- Scroll choreography, reduced-motion support, magnetic CTAs, project showcase, and timeline
- Downloadable résumé, custom 404, and crawler rules
- `.gitignore` rules for local Vercel state, dependencies, and environment files

See [SECURITY.md](SECURITY.md) for the security review and public-content note.
