# Fardeen Raza — Personal Portfolio

A personal portfolio website built to bring together my introduction, technical interests, selected projects, and contact information.

**Live website:** https://fardeen-raza-portfolio.vercel.app/

---

## Overview

This is a responsive static website built with semantic HTML, CSS, and vanilla JavaScript. The design focuses on clear presentation, thoughtful interactions, and a consistent experience across screen sizes.

The portfolio is a place to explore my work, learn a little about my background, and get in touch.

## Features

- Responsive layout and navigation
- Light and dark theme switching
- Dedicated sections for introduction, skills, projects, and education
- Interactive project showcase
- Scroll-based visual interactions
- Reduced-motion support
- Downloadable résumé
- Email contact actions
- Custom 404 page
- Security response headers and clean URLs configured for Vercel

## Built with

| Technology | Purpose |
|---|---|

## Run locally

No package installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/razacodes-any/fardeen-raza-portfolio.git
   ```

2. Move into the project directory:

   ```bash
   cd fardeen-raza-portfolio
   ```

3. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

4. Open the following address in your browser:

   http://localhost:8000

## Deployment

The website is deployed on Vercel.

To deploy your own copy:

1. Import the repository into Vercel.
2. Select the repository root as the project root.
3. Deploy it as a static site.
4. No build command or output-directory override is required.

The included `vercel.json` configures clean URLs and security response headers.
